# Archived Docs

`docs/archive/` is the historical side of the repo.

Rules:

- Files here are records, not active instructions.
- Archived plans, issue logs, and superseded specs must not be treated as the
  source of truth for current implementation work.
- Active architecture and execution guidance lives in:
  - `agent-rules/platform-architecture.md`
  - `agent-rules/software-stack.md`
  - `agent-rules/main-spec.md`
  - `agent-rules/test-requirements.md`
  - `docs/plans/2026-04-13-web-first-architecture-switch-implementation-high-level-plan.md`
  - `docs/plans/2026-04-13-web-first-architecture-switch-implementation-plan-runbook-v2.md`
- Future-looking native notes are allowed only in:
  - `apps/android/README.md`
  - `apps/ios/README.md`
